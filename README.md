# Playful Pathways Center

The center provides 5 main services:

1. Occupational Therapy


2. Speech Therapy


3. Special Education


4. Behavioral Therapy


5. Counselling



All these therapies are available for children.


Occupational Therapy Setup

The Occupational Therapy setup is play-based.

It does not have a typical doctor-patient seating arrangement.

The therapy is conducted through different play activities and therapeutic games.

The setup may include:

Ball games

Swings

Puzzles

Play equipment

Different activity-based therapeutic tools

A complete play/therapy area
